# Registration Form Automation using Jenkins (CI/CD)

## 📌 Project Overview

This project demonstrates a Continuous Integration (CI) pipeline using Jenkins to automate testing of a web-based registration form.

## 🛠 Technologies Used

* HTML, CSS (Frontend)
* Python (Automation Script)
* Selenium (Testing)
* Jenkins (CI/CD)

## ⚙️ How It Works

1. Jenkins pipeline is triggered
2. Dependencies are installed using requirements.txt
3. Selenium script runs automatically
4. Form is filled and submitted
5. Test result is displayed

## 📂 Project Structure

* index.html → Registration form
* style.css → Styling
* test_form.py → Selenium test script
* requirements.txt → Dependencies
* Jenkinsfile → CI pipeline configuration

## ✅ Output

* Automated form submission
* Console output: TEST PASSED
